Install in four steps

  1. Tap the download button above and wait for the APK to finish downloading.
  2. Open the file when your phone asks — or find it later in your Downloads folder.
  3. If Android warns you, allow installs from your browser (Settings → Install unknown apps). That prompt appears for every sideloaded app, not just FoldFX.
  4. Tap Install, open FoldFX, and activate your license key (License → paste key) to unlock everything.

Only download FoldFX from this page. If your browser or antivirus flags a sideloaded APK, that is expected — it happens because the beta is not distributed through the Play Store, not because anything is wrong.

Updating from 0.2.3 or older (including the previous 0.2.2 release)? Uninstall it first — the release signing key was rotated in 0.2.4, and Android refuses in-place updates across signing identities. Your license key stays valid; just activate it again.

About the build

Beta builds are the real thing now: version 0.2.6 is the signed release build — the exact APK buyers receive, shrunk and obfuscated with R8 and signed with the release key. Note that FoldFX ships without a free trial: after installing, activate a license key to unlock the wallpaper and system overlay (one key covers one device; deactivate it in-app to move it). Every build is checksum-verified: check downloads/checksums.txt before installing.
