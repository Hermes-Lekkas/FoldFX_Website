Install in four steps

  1. Tap the download button above and wait for the APK to finish downloading.
  2. Open the file when your phone asks — or find it later in your Downloads folder.
  3. If Android warns you, allow installs from your browser (Settings → Install unknown apps). That prompt appears for every sideloaded app, not just FoldFX.
  4. Tap Install, open FoldFX, and tune the transition with the on-screen slider.

Only download FoldFX from this page. If your browser or antivirus flags a sideloaded APK, that is expected — it happens because the beta is not distributed through the Play Store, not because anything is wrong.

About the build

This beta is a signed release build — not a debug APK. The code is shrunk and obfuscated with R8 in full mode: classes and methods are renamed to meaningless short names, the package structure is flattened, unused code and resources are stripped, and debug logging is compiled out. The APK contains nothing that can be read back into the original source, and the mapping file that could undo the renaming exists only on the developer's side — it is never published.
